# Detour — Live Sports Streaming Discovery App

Detour is a modern, high-performance web and mobile application for live sports streaming discovery. It helps users discover ongoing and upcoming sports events, watch highlights, read the latest sports news, and track matches.

## Features

- **Live Now**: View real-time match events, live streams, and instant score updates.
- **Highlights**: Browse cinematic summaries and catch up on key moments.
- **News**: Get the latest sports logs, editorial stories, and blog posts.
- **Detour Companion**: Interactive features for tracking matches and custom notifications.

## Tech Stack

- **Frontend**: Vite, React, Tailwind CSS
- **Mobile SDK**: Capacitor JS (Android)
- **Deployment**: Vercel

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Android deployment:
   ```bash
   npx cap sync android
   ```
